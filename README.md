# SENTINEL-FORGE

Enterprise Security Monitoring & Automated Incident Response Platform

## Overview

SentinelForge is a security monitoring and incident-response platform
designed to collect security telemetry from Windows, Linux, and Active
Directory environments, detect suspicious activity, correlate security
events, and automate selected response actions.

## Objectives

- Collect security telemetry
- Engineer security detections
- Correlate related events
- Investigate security incidents
- Automate incident response
- Map detections to MITRE ATT&CK
- Provide analysts with an incident-management interface

## Environment

- Windows Server / Active Directory
- Windows 11
- Linux
- Wazuh
- Sysmon
- Python
- FastAPI
- PostgreSQL
